# Requirements for RNN Agent

## Core Dependencies
torch>=2.0.0
numpy>=1.24.0
pandas>=2.0.0
matplotlib>=3.7.0
gymnasium>=0.29.0

## Optional (for enhanced functionality)
seaborn>=0.12.0  # For better visualizations
scikit-learn>=1.3.0  # For additional analysis tools
tensorboard>=2.13.0  # For training visualization

## Installation Instructions

### Option 1: Using pip
```bash
pip install torch numpy pandas matplotlib gymnasium seaborn
```

### Option 2: Using conda
```bash
conda install pytorch numpy pandas matplotlib -c pytorch
pip install gymnasium  # gymnasium not available in conda
```

### Option 3: Install from this requirements file
```bash
pip install -r requirements_rnn.txt
```

## Verification

After installation, verify PyTorch is working:

```python
import torch
print(f"PyTorch version: {torch.__version__}")
print(f"CUDA available: {torch.cuda.is_available()}")
```

## Notes

- **CPU vs GPU**: The RNN agent works fine with CPU for this task size
- If you want GPU acceleration (optional), install CUDA-enabled PyTorch:
  ```bash
  # For CUDA 11.8
  pip install torch --index-url https://download.pytorch.org/whl/cu118
  
  # For CUDA 12.1
  pip install torch --index-url https://download.pytorch.org/whl/cu121
  ```

- The agent is tested with PyTorch 2.0+, but should work with 1.13+
